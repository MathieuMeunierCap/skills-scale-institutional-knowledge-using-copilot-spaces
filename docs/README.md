# OctoAcme Project Management Docs — README

Welcome! This folder collects living documentation for project/program management at OctoAcme.

## What is this?

This README provides a gateway to the processes, templates, and guides used in OctoAcme projects for planning, execution, release, risk management, and retrospectives.

## Summary of OctoAcme Project Management Processes

OctoAcme follows a structured, lifecycle-based approach to project management that emphasizes customer value, iterative delivery, and clear ownership. The methodology is organized into five key phases: **Initiation**, **Planning**, **Execution**, **Release**, and **Retrospective & Continuous Improvement**. Each phase is guided by core principles including customer-first prioritization, data-informed decision-making, and psychological safety.

**Key Workflows & Execution Model:**
- Customer-centric and iterative: Prioritize customer outcomes and deliver in small, testable increments.
- Clear ownership and roles: Each project has an assigned Project Manager (PM) and Product Manager (PdM), supported by Developers and QA/Testing teams.
- Artifacts and checklists: Use one-pagers, risk registers, release plans, backlogs, and retrospectives to keep projects actionable and transparent.
- Communication cadence: Daily standups (15 min), weekly delivery syncs, end-of-sprint demos, and monthly stakeholder updates ensure alignment.
- Quality embedded throughout: Unit tests, integration tests, end-to-end smoke tests, security scanning in CI, and manual QA for feature acceptance.

**Risk Management & Stakeholder Communication:**
- Maintain a Risk Register (ID, description, impact, likelihood, owner, mitigation status) reviewed weekly.
- Use structured weekly status templates covering progress, next steps, risks/blockers, and decisions needed.
- Three-level escalation for blockers: team-level triage → PM-to-Product Lead → sponsor involvement.
- Conduct blameless retrospectives after each sprint, release, or incident to capture learnings and drive continuous improvement.
